# jlstgco.com

Website for J&L Co. Ltd. (Marketing Strategy for Technology).

Hosted on GitHub Pages. Every change saved to the `main` branch goes live on jlstgco.com in a minute or two.

## Which file is which page

| Page | File |
|---|---|
| Home | `index.html` |
| Approach & Services | `approach.html` |
| About | `about.html` |
| Contact form | `contact.html` |
| Page not found | `404.html` |
| Colors, fonts, spacing | `styles.css` |

## How to change text on GitHub

1. Open the file above on github.com and click the pencil icon (Edit this file).
2. Use Ctrl/Cmd + F to find the sentence and change the words only. Leave the `<tags>` as they are.
3. Click **Commit changes**, add a short note (for example "Update About headline"), and confirm.
4. Wait about a minute, then refresh jlstgco.com.

To undo a change: open the file's History on GitHub, find the earlier version and restore its text.

Contact form submissions go through Web3Forms to the email registered with the access key (currently jerrywei.lee@gmail.com). Keep the `CNAME` file: it tells GitHub Pages to serve jlstgco.com.
